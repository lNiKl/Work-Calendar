# Work-Calendar
Умный календарь для учёта рабочих дней и расчёта зарплаты

🎯 Основные функции
📊 Визуальный календарь с цветными отметками о типах дней

💼 Учёт рабочих дней с почасовой или посменной оплатой

📈 Статистика и аналитика по заработку и отработанному времени

💱 Автообновление курсов валют через API
